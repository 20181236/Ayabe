# 🎮 프로젝트명
Ayabe(임시,仮)
## 📝 작업 의도
Ayabe은 Unity 엔진을 활용해 제작된 개인 포트폴리오 프로젝트입니다.  
디자인 패턴 및 프로그래밍 기법 적용을 통해 개발 역량을 끌어올리는 것을 목표로 했습니다.
이 프로젝트는 『블루 아카이브(Blue Archive)』의 전투 UI, 연출, 전투 흐름 등을 기반으로 Unity로 직접 구현한 모작입니다. 또한 다른 게임에서 인상 깊었던 메커니즘을 선택적으로 적용하여 게임 시스템 구성 능력을 강화했습니다.
